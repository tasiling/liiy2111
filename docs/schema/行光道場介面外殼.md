## 範圍

依擁有者指示,直接沿用雛形的 CSS 變數、版面結構、元件樣式(卡片、按鈕列、底部導航、
bottom sheet、時間軸),不重新設計、不「順手優化」。這階段只做外殼與導航,既有功能

## CSS 移植

`app/dojo.css` 是雛形 `<style>` 內容的逐條搬移,唯一調整是所有選擇器加上 `.dojo`
前綴做範圍限定(雛形原本用 `:root`/`body`/`*` 等全域選擇器,直接搬進既有 Next.js 專案
會影響到還沒重新編排的頁面;等全部頁面都掛進場域殼層後,這層限定可以再檢視要不要
拿掉)。變數名稱、顏色值、間距、圓角、字體全部照抄,沒有更動任何一個數值。

## 雛形本身的三個問題(已修)

1. **快速新增表單的 `<select>` 全改按鈕列**:場域、光念、隱私三個欄位原本是
   `<select>`,現在照雛形計時器頁(`setMinutes`/`pickTimerSpace`/`pickTimerNen`)的
   按鈕列做法,全部改成可點選、有 `.on` 高亮的按鈕列(`app/components/DojoShell.tsx`
   的 `QuickAddModal`)。全站(含新殼層)已確認沒有任何 `<select>` 元素。
2. **計時器結束分鐘數寫死用 25 分計算的 bug**:雛形 `finishTimer()` 不論選了
   25/45/60/90 分,一律用 `25*60` 起算已投入分鐘數,導致選 45 分以上時記錄的分鐘數
   是錯的。修正為用實際選定的起始秒數(`initialSeconds`,由 `setMinutes()` 設定)
   計算(`app/timer/page.tsx`)。
3. **居所「接續中的事」排除私密項目**:`app/page.tsx` 的 `HomePage` 在
   `entries.slice(-3).reverse()` 之前先 `filter((e) => e.privacy !== "私人")`。
   雛形內建的 3 筆示範資料全部是「私人」,所以修正後居所首頁的「接續中的事」預期會
   顯示空狀態,這是正確行為,不是資料遺失。
